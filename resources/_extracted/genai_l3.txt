What are Runnables?
In LangChain, a Runnable is the base interface for any
component that can be executed (run) in a chain.
Runnable is a base interface,
If you’re a Runnable, you must support at least .invoke(),
.batch(), and .stream().

===== PAGE 22 =====

What is LLM grounding?
Anchoring an LLM’s responses to real, external data so answers are
factual, relevant, and reliable.
Why use it?
To reduce hallucinations, improve accuracy, and build user trust.
When to use it?
When answers must be up-to-date, verifiable, or based on private data.
