===== PAGE 39 =====

No Schema Enforcement in Prompt-Based Outputs
Even with explicit instructions, there is:
 ❌  No enforcement of format
 ❌  No validation of fields
 ❌  No guarantee of consistency
GenAI

===== PAGE 40 =====

What is structured Output?
When we say “structured output” by an LLM, it means
instead of giving a free-form text answer, the model
returns data in a machine-readable, organized format —
usually JSON, key-value pairs, or something that follows a
predefined schema.
GenAI

===== PAGE 41 =====

Unstructured LLM Output

What is the weather in New York today?

GenAI

===== PAGE 42 =====

Structured LLM Output
Prompt →  LLM
What is the weather in New York today? 
Return the answer strictly in 
JSON format with the following fields:
- location (string)
- temperature_celsius (number)
- condition (string)
- wind_speed_kmh (number)
LLM →  Response
{
  "location": "New York",
  "temperature_celsius": 18,
  "condition": "light rain",
  "wind_speed_kmh": 12
}

etc.).
